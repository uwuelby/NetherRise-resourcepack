# NetherRise resource pack

This repository mirrors the public NetherRise server resource pack so players can download it when the primary host is unreachable.

- Minecraft server: `mc.netherrise.uz`
- Pack: `NetherRise-resourcepack-v25.zip`
- SHA-1: `dd0d2b9b685d2ee08fd0a4aa0797e0827fc1fca0`

Download the ZIP without extracting it. In Minecraft, put it in the `resourcepacks` folder and enable it under Resource Packs. The in-game `/pack` command requests automatic installation.
